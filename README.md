# 🌍 PB-MAPS: Guía Turística y Hotelera de Puerto Boyacá

Bienvenido al repositorio de PB-MAPS. Este proyecto tiene como objetivo crear una plataforma web para promocionar y gestionar la información de los lugares turísticos y hoteles de Puerto Boyacá.

## 👥 Roles del Sistema

1.  **Usuario Público:** Visualiza lugares y hoteles disponibles.
2.  **Administrador:** Panel CRUD (Crear, Leer, Actualizar, Eliminar) para la gestión de contenido.
